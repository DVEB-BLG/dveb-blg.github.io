# ДВЭБ — Дальневосточное бюро экспертиз

Сайт органа инспекции. Благовещенск, Амурская область.

## Структура
- `index.html` — главная страница
- `quiz.html` — форма заявления на инспекцию
- `consult.html` — форма консультации
- `css/styles.css` — дизайн-система (Stem, #003070 / #20B0A0)
- `js/main.js` — интерактив (меню, scroll reveal, квиз)
- `fonts/` — шрифт Stem (7 весов)
- `assets/` — логотип, фавиконы, бренд-материалы

## Деплой
GitHub Pages — автоматическая публикация из ветки `main`.
